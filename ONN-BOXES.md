# Device Inventory

The physical device inventory for a deployment — box names, MAC addresses, IP
reservations, panel quirks, and per-box roles — is **deployment-specific** and
is **not committed** to this repository. Maintainers keep it in operator-local
notes under `docs/ops-local/` (gitignored).

If you are setting MyMTS up yourself, you only need your own device(s); see
[`ONBOARDING.md`](ONBOARDING.md) to get the app and helper running locally.

> **Maintainers:** keep device addresses, MACs, and host paths in
> `docs/ops-local/` only — never in committed docs (the *audience-aware docs*
> standard).
